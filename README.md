Fala, dev! 👋 Sou o Lucas Baldez, estudante do Colégio Pedro II e entusiasta de tecnologia, com foco em lógica de programação e desenvolvimento de software. Estou construindo uma base sólida para me tornar desenvolvedor Full Stack, com ênfase em Backend.

Sobre mim

Estudo no Colégio Pedro II, no Rio de Janeiro, e hoje me dedico principalmente a lógica de programação, estruturas de dados e desenvolvimento web (HTML, CSS e JavaScript), enquanto aprofundo meus conhecimentos em C#. Tenho interesse especial em engenharia de software, arquitetura backend e desenvolvimento de jogos 3D com Unreal Engine.

Como eu aprendo

Prefiro entender os conceitos a fundo em vez de decorar sintaxe, priorizando sempre o raciocínio lógico. Tenho facilidade para quebrar problemas complexos em etapas simples e funcionais, e gosto de aprender na prática, testando e iterando rápido. Também procuro manter atenção aos detalhes, escrevendo código limpo, organizado e com um bom controle de versão.
